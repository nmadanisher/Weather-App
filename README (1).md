# 🌤️ Weather Application (SkyCast)

A modern, responsive Weather Web Application built with HTML, CSS, and JavaScript. This project displays real-time weather details including humidity, wind speed, atmospheric pressure, and a 5-day forecast.

---

## 🚀 Features

- 🔍 **City Search:** Look up weather details for various cities.
- 🌡️ **Weather Metrics:** Displays temperature, humidity, wind speed, pressure, and visibility.
- 📅 **5-Day Forecast:** Visual forecast cards for upcoming days.
- 📱 **Responsive Design:** Clean glassmorphic layout optimized for desktop and mobile devices.
